Reference fragments from the current release. They are NOT a complete build chain. Root HTML, the corresponding JavaScript in `assets/`, and Sass source in `styles/` are authoritative. The flow fragment has a question-data substitution marker, and v7.css is a cumulative-addition fragment, not the entire stylesheet. Update the external HTML, Sass, or JavaScript files, then run `npm run prepare:publish` before a Cloudflare Pages deployment. Legacy builders depending on excluded backup HTML are intentionally not included.
